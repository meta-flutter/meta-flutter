# meta-flutter-apps

Flutter and Dart application recipes for meta-flutter, generated and rolled
with the SDK pin.

Not standalone: every recipe here inherits flutter-app or flutter-app-native
from meta-flutter, so flutter-layer has to be in bblayers.conf. See the
top-level README for the layer stack and the development flow.

Maintainer: Joel Winarske <joel.winarske@linux.com>

Send patches as pull requests against the branch for your release.
